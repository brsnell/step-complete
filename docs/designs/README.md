# Designs

Approved design docs for STEP Complete features, one file per feature
(`<feature>.md`). A design says what we are building and why, the decisions taken and what is
out of scope; mark it `Status: APPROVED` once agreed.

Dated implementation plans live in `docs/superpowers/plans/` (`YYYY-MM-DD-<topic>.md`). The
product plan and milestones are in `docs/PLAN.md`; the working order of what comes next is
`TODOS.md`, with `docs/whats-next.md` pointing at it.
